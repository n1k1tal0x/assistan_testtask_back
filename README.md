# Модуль «Заявка на отпуск» — Backend

## Стек

- Node.js + TypeScript
- Fastify
- PostgreSQL (поднимается через Docker Compose)

## Что реализовано сейчас

- Скелет Fastify-приложения на TypeScript (`src/index.ts`), один роут `GET /` → `{ status: "ok" }`.
- `Dockerfile` — multi-stage сборка (build со `tsc`, затем лёгкий прод-образ только с `dist/`).
- `docker-compose.yml` — сервис `app` (порт `3000` наружу) и сервис `db` (`postgres:16-alpine`).
  БД не публикует порт наружу и не смотрит во внешнюю сеть — доступна только сервису `app`
  внутри внутренней docker-сети `internal`.

Бизнес-логика заявок (эндпоинты, валидация, подключение к БД) пока не реализована.

## Подход к БД: code-first

Схема базы данных не пишется вручную в виде `.sql`-файлов. Таблицы/структуры будут описаны
в коде на TypeScript (модели/сущности), а схема и миграции для PostgreSQL — генерироваться
из этого кода (ORM/query-builder с поддержкой миграций). Источник истины — код приложения,
а не отдельно поддерживаемая SQL-схема.
